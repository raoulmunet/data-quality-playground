# Data Quality Playground

Define simple, readable data-quality rules and run them against CSV data in the browser.

## Supported starter rules

- `column NOT NULL`
- `column UNIQUE`
- `column >= number`
- `column <= number`
- `column IN value1,value2,...`
- `column MATCHES /regex/`

## Output

The tool reports pass/fail counts, percentages and the rows that violate each rule.

## Privacy

All processing is local.
